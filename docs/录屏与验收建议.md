# 录屏与验收建议

附件3要求大量“成功录屏 / 错误码录屏 / 警示录屏”。本项目的输出专门按录屏设计。

建议每项测试录屏时同时显示：

1. 命令行执行命令；
2. 当前测试账号；
3. `[RESULT] PASS/FAIL`；
4. 关键 YD 回调（LOGIN / ORDER / TRADE / API_EVENT）；
5. 如经纪商要求，可同时打开 ydClient 对照报单、成交、持仓和资金。

## 示例：2.1 连通性

```bat
build\bin\test_01_connect.exe --accounts config\accounts.local.csv
```

屏幕应出现：

```text
PASS | TCP trade connected
PASS | account login
PASS | static data ready
PASS | history caught up
```

## 示例：2.3 连接异常

程序会主动调用 YD `disconnect()`，日志应依次出现：

```text
PASS | disconnect detected
PASS | reconnect detected
PASS | reconnect caught up
```

## 示例：2.7 指令检查

程序不会把三个已知错误指令发到柜台，而是在调用 `insertOrder` 之前拦截：

```text
PASS | invalid instrument rejected locally
PASS | invalid minimum price tick rejected locally
PASS | over max single-order volume rejected locally
```

## 多账户

每个账户单独目录：

```text
output/<time>/<test>/<account>/test.log
```

总结果：

```text
output/<time>/summary.csv
```

便于最后把 10 个账户的结果汇总到测试报告。
